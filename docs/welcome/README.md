# EatMates landing page

Published by GitHub Pages from `main`, under `docs/welcome/`. The existing app and invitation routes stay at their original URLs.

Replace `demo.mp4` with the final video and `poster.png` with its preview image. Update the visible text description in `index.html`. If the final clip includes speech or meaningful sounds, also add an accurate Hebrew WebVTT caption track inside the video element. The page starts the clip muted when the visitor allows autoplay and respects reduced-motion preferences.

The iPhone button opens the existing web app. On iOS, volume is adjusted using the device controls if Safari disables programmatic volume changes.
